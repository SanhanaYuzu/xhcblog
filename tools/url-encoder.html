URL 编解码

支持 encodeURIComponent 与 encodeURI 两种标准

操作模式
编码标准
输入 0 字符
结果 0 字符

encodeURIComponent：编码除 A-Z a-z 0-9 - _ . ! ~ * ' ( ) 外的所有字符，适合编码「查询参数的值」。
encodeURI：保留 : / ? # [ ] @ ! $ & ' ( ) * + , ; = 等 URL 结构字符，适合编码「一整条链接」。
解码遇到非法百分号序列（如 %ZZ、单独的 %）时会给出明确提示。
