XEBZ 是什么：XHCBZ v2.8 —— XHC 生态原创独立压缩格式，与 zip/rar/7z 结构完全不同： 自研容器（magic + 可选加密头）+ 多文件归档清单（含 crc32 校验）+ 全自研 XHCZ-Optima 算法（六边形战士）（块级在 ss / z3 / z4 / z6 / ProSS / 原样存储 六策略间逐块取最小，构造上保证每类数据压缩率均≥历史最优：中文/代码/英文取 z4、高阶中文取 z6、日志取 z3、CSV/日志取 ProSS、高重复流取 SS）+ XHCZ-ProSS 算法（综合产品线：增强 LZ 融合 z3/z5/SS 之长 + 智能四档分派：PRO 三模型混合 / 均衡双模型 / 快速单模型 / 原样存储，压缩率全面超越 z6）+ XHCZ6 算法（PAQ 式双模型混合）+ XHC-SS SpeedSafe I（速度+安全：快速 LZ+哈夫曼，配 Combo2 加密 = 一键 SpeedSafe） + XHC-Combo2 安全内核： Argon2id（抗 GPU 暴力破解的现代 KDF，默认 32MB/3 次）+ ChaCha20-Poly1305（RFC 8439 认证加密）， 安全强度全面超越 PBKDF2+AES-GCM 旧方案；可选 XHC-Combo3 强化内核（Argon2id 64MB + 双层加密，512-bit 极难破解）；兼容 1.0~2.6 全部旧包。 可选 AES-256-GCM 加密（PBKDF2 10 万次迭代）。解压自动校验 crc32，损坏立即报错。 打包时可手动选择压缩算法（自动择优=XHCZ7·XHCZ-Optima·XHCZ-ProSS·XHCZ6·XHCZ5·XHCZ4·XHCZ3·XHCZ2·XHC-SS·Combo / 仅存储）， 压缩后比原文件大时自动回退为原样存储，绝无膨胀。 全部在前端本地完成，文件不上传服务器。
命令行：python xebz.py pack-dir ./docs -o docs.xebz -p 密码 -m pro / python xebz.py unpack docs.xebz -d ./out
