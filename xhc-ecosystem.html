🚀 XHCZ 压缩算法演进

XEBZ 压缩格式内部历经四代算法迭代——从自研 RLE+Huffman，到对标 RAR5、7z 的现代熵编码，全部实现完全原创。
XEBZ 1.0 · XHC-Combo
自研压缩管线：RLE-X 游程变换 → Huffman-256 规范哈夫曼

原创组合管线，每个文件自动在 combo 与 store 间择优。文本压缩率 40%~70%。

XEBZ 2.0 · XHCZ2
自研哈希链 LZ 匹配 → 自研 32-bit 整数算术编码 对标 RAR5 思路

匹配引用 + 熵编码双阶段（RAR5 同思路、实现全原创），中文文本压缩率降至 4% 以下。

XEBZ 2.1 · XHCZ3
1MB 大窗口 LZ + lazy 延迟匹配 + 距离分层 + 分块自适应编码 RAR5 级增强

窗口 32KB→1MB、智能匹配决策、长距离分层编码；混合分布大文件压缩率显著提升。

XEBZ 2.2 · XHCZ4 7z/LZMA 级
自适应二进制算术编码 + 动态概率模型 当前最优

每个 bit 用 11-bit 动态概率（编码一位更新一次）+ 上下文建模，无需分块。中文文章压缩率 1.4%，全面碾压前代——这就是 LZMA 碾压静态频率的核心机制。
